# Fix-WiFi

Read-only scripts that find common causes of slow Wi-Fi: weak signal, interference, 2.4 GHz or overlapping channels, crowded channels, packet loss or latency to the router, too many devices, slow DNS, and ISP problems.

- **macOS / Linux:** `bash wifi-diagnose.sh`
- **Windows (PowerShell):** `powershell -ExecutionPolicy Bypass -File .\wifi-diagnose.ps1`

Run it on the device that feels slow, from the spot where it's slow. Each finding comes with a suggested fix.
